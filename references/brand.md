# AI GO 品牌規範（手冊用）

手冊一律套 **AI GO 共用母版的 B2B 模式**（`母版_B2B.html`／aigo-deck skill 的 `tokens.md`、`b2b.md`）。
判準：讀者會不會在沒有人講解的情況下自己讀完？手冊會 → B2B。

`scripts/deck.css` 已經把下面的規則寫好；寫內容時**不要改色、不要自訂字體、不要加裝飾**。

## 色彩

| Token | Hex | 手冊裡用在 |
|---|---|---|
| `--blue` | `#1F80FF` | 品牌藍：每頁左緣 5px 直條、眉標、步驟編號、圖解編號框、卡片左線 |
| `--blue-deep` | `#003685` | 淺底上的強調（info 標籤文字） |
| `--cyan` → `--blue` 漸層 | `135deg #4DC9EC→#1E7FFF` | **唯一允許的漸層**：流程圖的「AI」節點、步驟終點、記憶層「客人這一則」 |
| `--bg-dark` | `#050E1F` | 封面、分隔頁、封底、注意框（深底收束卡）、瀏覽器框 |
| `--panel` | `#0C1B33` | 瀏覽器框底色 |
| `--bg-soft` | `#E9EEF4` | 截圖多的頁（`bg="soft"`） |
| `--bg-soft-2` / `--tint` | `#F3F5F8` / `#E6F4FF` | 一般提示框、表格高亮列 |
| `--ink` / `--ink-2` / `--ink-3` | `#050E1F` / `#5C626D` / `#8E9CB1` | 主文字／次要文字／註解與頁碼 |
| `--on-dark-2` | `#AFC4E0` | 深底次要文字（偏藍灰，不要用純灰） |

狀態色（綠、琥珀、紅）只用在**對應 App 畫面上的狀態標籤**（例：AI 回、待人工、人工回應中），不當裝飾色。

## 字體

`"Helvetica Now Display", "Inter", …, "Noto Sans TC", "PingFang TC", "Microsoft JhengHei"`。
中文標題 700；內文 400、行高 1.6～1.7；數字開 `tnum`。

## 畫布與幾何

- 母版 1280×720；手冊用 **1600×900（×1.25）**，截圖空間較大
- 安全邊界：左右 104、上 60、下 66（頁尾在下方 26）
- 每頁左緣藍色直條（封面、分隔頁、封底也有）
- 圓角：卡片 8、截圖框 12、logo 16；**不用陰影**
- 卡片：母版三欄卡片樣式（左 3px 藍線、無外框）

## 固定頁

| 頁 | 底色 | 內容 |
|---|---|---|
| 封面 | 深 | AI GO 圖標、眉標「AI GO · 租戶名 · 操作手冊」、App 名＋手冊名、一句話、**製作日章**、底部資訊列（租戶／App／版本／對象）、右側瀏覽器框主畫面 |
| 分隔頁 | 深 | 「PART A」眉標、大標、一句話、本部分頁目 |
| 內容頁 | 白（截圖多的用淺灰） | 眉標（部分名）＋標題＋導言＋內容；頁尾左「AI GO · 租戶名　手冊名 · 部分」、右「07 / 41」 |
| 封底 | 深 | AI GO 圖標、一句話、摘要、聯絡列（固定帶 `Urfit Technology Co., Ltd. · Taipei`、`ai-go.app`） |

## 截圖

- 品牌規則：**產品截圖不裸貼**。全頁截圖自動包深色瀏覽器框（三個圓點）；局部截圖白底細框
- 截圖多的頁用 `bg="soft"`，讓截圖落在淺灰襯底上
- 圖解編號用品牌藍 `#1F80FF`

## 檔名

**「AI GO 租戶名 App名 YYYYMMDD」**，PDF 與 HTML 同名。例：`AI GO 展示股份有限公司 Shopline 電商智能客服展示 20260928.pdf`

- 租戶名：`/api/v1/auth/me` 的 `tenant_name`（`discover.mjs` 自動寫進 `disc/meta.json`）
- App 名：平台上的 App 名稱（＝頁面標題去掉「 — AI GO」）
- 日期：製作日（台灣時間），與封面的製作日章一致
- 檔名不能用的字元（`<>:"/\|?*`）自動換成底線

## 絕對不要

- 換品牌藍、加第二種漸層、用漸層文字
- 陰影堆疊、emoji 當 icon、裝飾線框
- 網址寫 `https://www.ai-go.app`（一律 `ai-go.app`）
- 編造客戶名稱、數字或案例
