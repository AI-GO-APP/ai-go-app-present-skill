# 踩雷清單（實戰紀錄）

依發生階段排列。每一條都真的發生過。

## 登入與環境

- **帳密檔不只一份**：`~/.aigo/.env`、工作區 `.aigo/.env`、`~/.aigo-transfer/.env` 可能指向不同帳號或過期密碼（實測 `~/.aigo/.env` 回 401、工作區那份才對）；登入失敗先確認 `env_file` 指的是哪一份。
- **從子目錄執行登錄腳本會登入錯租戶**（demo 與正式共用 auth，照樣回 201）：確認截圖畫面的租戶名稱。
- puppeteer-core 找不到：在 skill 目錄 `npm install`，或工作目錄自己裝。

## 截圖

- **PopMenu 用程式點擊會跑到左上角**：選單位置取自 `event.clientX/Y`，程式 `el.click()` 是 0。用 `mouseClick`。
- **選單和觸發按鈕取聯集**會夾到中間不相關的畫面；只取選單第一項與最後一項。
- **視窗截整頁**縮進頁面後看不清；截 `.modal` 本身。
- **內層捲動沒歸位**：測試對話截到一半的回覆。截圖前設好 `scrollTop`。
- **點開對話會把未讀歸零**：拍前備份、拍後還原；還原時如果截圖期間真的有新訊息，數字會對不上，屬正常。
- **示範資料是空的**：面板顯示「尚未建立」沒有教學價值；用 app 的 action 預填，或送一則測試訊息讓系統自己產生。
- **送測試訊息會真的推到 LINE**：只對自己的測試帳號做。
- **模式切換拍完要切回**，而且要確認切回成功（在計畫裡檢查原本的按鈕還在不在）。

## 截圖時抓到的產品 bug（截圖就是 UI 驗收）

- 面板永遠顯示「尚無記憶紀錄」：前端共用呼叫函式已經拆掉 `{status, result}` 信封，元件又讀一次 `.result`。後端測試全過，只有畫面看得出來。
- 清單欄位顯示 `['…']`：後端把 list `str()` 成字串存起來。
- 區塊只有標題沒有內容：條件只處理了有明細的情況。

這類修正要照 app 的發布規則上線（發布 → PR → merge），並記進 app 的評估紀錄；修完重拍。
動手前先過 `workflow.md` P4 的確認清單——下面三種都被誤當成 bug 過：

- **簽核攔截**：預設表的寫入回 `approval_status: pending`，畫面顯示「待簽核」。是租戶簽核規則，不是錯。
- **空資料**：面板「尚未建立」是因為示範資料沒預填，不是前端壞掉。
- **程式點擊**：選單跑到左上角是 `el.click()` 沒有座標，是截圖方式的問題。

## 內容

- **探勘讀過的設計脈絡會滲進手冊**：讀完原始碼與 CHANGELOG 後，導讀頁、分隔頁、參數頁很容易寫出「這個功能是為了…而設計」「v12 起改成…」「後端會先…再…」。讀者只需要「是什麼、在哪、怎麼操作、改了會怎樣」；寫完用刪除測試掃一遍（`writing-guide.md`「不插播」）。
- **截圖時修的 bug 被寫進手冊**：那是製作過程，放交付對話，不放手冊。

- **前端說明文字可能過時**：例如開關的 hint 說「關閉時仍可…」，實際後端兩個開關效果一樣。以後端程式為準。
- **「目前值」憑印象寫會錯**：一律從設定 API 讀，附錄用程式產生。
- **沒查證的推論會混進去**：例如「旅程在客人婉拒後不打擾」——程式裡沒有就刪。
- **把事實寫進人設**：手冊要教使用者「規定放知識庫、語氣放人設」，自己寫範例時也要遵守。
- 範例和截圖用真實客戶的品牌或人名時，確認這份文件的讀者可以看；要對外的版本先去識別。

## 排版

- **封面標題孤字斷行**（「操作手」＋「冊」）：`white-space: nowrap` 或縮字級。
- **提示框在直欄裡被撐成一大塊**：`.note` 預設 `flex: none`，只有在橫排 `.row` 裡才 `flex: 1`。
- **兩張並排圖超出右緣**：內容區只有 1392，兩張各 ≤ 680。
- **封面主畫面被右緣切掉**：寬度 ≤ 720。
- **版面檢查器的假陽性**：封面、分隔頁、頁尾不在 `.content` 內，不要算。
- **擠壓重疊**：內容總高超過內容區時，flex 會把上方的 `.row` 壓扁，截圖和下方表格重疊——下緣檢查抓不到。`render.mjs` 會檢查 `scrollHeight > clientHeight`；修法是給上方圖片加 `maxh`。
- **全頁截圖包瀏覽器框後多 26px**：原本剛好塞滿的頁會溢出，全景圖寬度從 1040 降到 960～1000。
- 左欄兩張圖疊太高、圖說壓到頁尾：第二張移到右欄底部。
