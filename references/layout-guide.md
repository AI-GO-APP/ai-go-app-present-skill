# 版面規格

## 畫布

| 項目 | 值 |
|---|---|
| 頁面 | 1600×900 px（16:9），PDF 每頁同尺寸 |
| 樣式來源 | AI GO 共用母版 B2B（1280×720）× 1.25，見 `brand.md` |
| 邊距 | 左右 104、上 60、下 66（頁尾在下方 26）；左緣 5px 品牌藍直條 |
| 標題區 | 眉標（部分名）14px 藍、標題 40px、導言 18px 灰，約佔 140px |
| **內容區** | **約 1392×650** —— 所有圖與表要塞進這裡 |
| 字型 | Inter ＋ Noto Sans TC（Google Fonts，退回微軟正黑體） |

## 圖片尺寸建議

| 版型 | 圖寬 |
|---|---|
| 全景圖解＋右側編號說明 | 960～1000（全頁截圖會多 26px 瀏覽器框） |
| 左圖右表 | 圖 560～640，表佔其餘 |
| 兩張並排 | 每張 ≤ 680；下方還有表格時再加 maxh 330 |
| 三欄小圖（側欄面板） | 每張 220～260 |
| 細長圖（收件匣欄、手機畫面） | 高 ≤ 560～620，單獨一欄 |
| 封面主畫面（瀏覽器框） | 720 |

`Deck.shot(name, maxw, maxh)` 會等比縮到兩個上限都滿足。

## 字級

| 元素 | 大小 |
|---|---|
| 內文、步驟 | 16～17 |
| 表格（compact／dense） | 15／14.5 |
| 圖說 | 14 |
| 編號圓點 | 28px 圓、15 字 |

1600 寬的頁面在螢幕上 100% 顯示時，15px 約等於一般文件 11pt。低於 14 不要用。

## 顏色

全部照 `brand.md`（AI GO 品牌 token），**不提供換色參數**。App 自己的品牌色只會出現在截圖裡。
- 圖解編號、步驟編號、眉標：品牌藍 `#1F80FF`
- 提示框：一般＝淺灰底＋左藍線；注意（`note(..., "warn")`）＝深底收束卡
- chip：只用來對應 App 畫面上的狀態（ok 綠、warn 琥珀、info 藍、danger 紅）

## 檢查表（G4）

總表先看一輪，再開有疑慮的單頁：

- [ ] 沒有東西壓到頁尾、超出右緣或**擠壓重疊**（`render.mjs` 三種都會列，只看 `.content` 內）
- [ ] 封面後面是**目錄頁**，每個 PART 都在、頁碼對得上（`render.mjs` 會驗頁碼）；標題沒有被截成「…」到看不懂
- [ ] PDF < 20 MB；超過且壓不下來時已經問過使用者（`workflow.md` P7）
- [ ] 圖說沒有和頁尾重疊
- [ ] 標題沒有孤字斷行（封面標題特別注意，用 `white-space: nowrap` 或縮字級）
- [ ] 提示框（note）沒有被撐成一大塊空白（直欄容器裡 note 要 `flex: none`）
- [ ] 截圖縮太小看不清的 → 換局部截圖或拆頁
- [ ] 同頁兩張圖高度差太多時，改成上下或單欄
- [ ] 每一部分的頁數大致符合大綱的比重

## 常見修法

| 問題 | 修法 |
|---|---|
| 右欄內容太多往下溢出 | 表格改 `dense`、刪一列、把圖改小，或拆成兩頁 |
| 左欄兩張圖疊起來太高 | 把第二張移到右欄底部，旁邊放圖說 |
| 視窗截圖太小 | 改截 `.modal` 本身，不要截整頁 |
| 頁面下半部大片空白 | 放大截圖、控制點地圖加 `min-height`、或把相關內容併進來 |
| 目錄列被截成「…」 | 縮短該頁標題（目錄列就是頁標題，約 16 字內） |
| 目錄拆成兩頁 | 正常（一個 PART 超過 18 頁時會出「（續）」欄）；想收成一頁就合併頁數 |
| PDF 超過 20 MB | `render.mjs` 會自動整份壓縮；壓不下來看它列的「原檔最重的頁」，把全頁截圖換成局部或拆冊 |

## 目錄頁

`Deck.write()` 自動產生，每個 PART 一欄（最多 4 欄）：

| 項目 | 規則 |
|---|---|
| 位置 | 封面後面；或 `d.toc()` 呼叫的位置。沒呼叫也會自動補 |
| 分組 | 分隔頁＝一組（PART 標籤＋標題）；第一個分隔頁之前的頁歸「開始之前」 |
| 列 | 每頁標題一列＋頁碼；封面、目錄、分隔頁、封底不列；`raw()` 頁有給 `title` 才列 |
| 字級 | 每欄 ≤ 12 列 15.5px；更多切 dense 14.5px（每欄 18 列）；再多拆成「（續）」欄與「目錄（續）」頁 |
| 讀法列 | 底部一行（編號、情境 → 結果、注意）；列太多放不下時自動省略，`toc(howto=False)` 可關 |
| PDF | 每列是可點的內部連結；另依分隔頁與頁標題產生書籤側欄 |
